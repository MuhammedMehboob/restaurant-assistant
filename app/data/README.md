# Sample data

"Saffron & Olive" is a fictional restaurant made up for this learning project.
The menu, prices, phone number, email and policies are all invented.

- menu.csv: 35 dishes. Yes/no columns use 1 = yes, 0 = no. spice_level is 0 (not spicy) to 3 (hot). Prices are in GBP.
- policies/: five text documents about opening hours, bookings, allergens, delivery, refunds and offers.
